# SignalVault 快速开始

> 5 分钟完成第一次使用。

## 1. 安装

**双击 `SignalVault.app`** 即可启动。

首次启动时，macOS 可能会提示"来自未识别的开发者"。如果遇到这个提示：
1. 打开 **系统设置 → 隐私与安全性**
2. 找到 SignalVault，点击"仍要打开"

SignalVault 的所有数据保存在本机，不上传到任何服务器。

## 2. 第一次启动

双击应用后：

1. **应用会在后台启动服务**（可能需要 5–15 秒）
2. **浏览器会自动打开** SignalVault 页面
3. 如果浏览器没有自动打开，手动访问：**http://127.0.0.1:8000**

首次打开会看到**欢迎向导**，引导你完成基础设置。

> 关闭浏览器不会停止服务。要退出应用，按 `Cmd+Q` 或在菜单栏选择退出。

## 3. 配置 AI

SignalVault 需要 AI 来分析你导入的资料。有两种方式：

### 方式一：先用 Mock 模式体验（推荐首次使用）

- 选择 **Mock** 模式
- 不需要填写任何 Key
- 可以体验完整流程，但分析结果是模拟的

### 方式二：用自己的 AI 服务

需要准备：
- **Provider**：选择 `OpenAI Compatible`
- **Base URL**：你的 AI 服务地址（如 `https://api.openai.com/v1`）
- **Model**：模型名称（如 `gpt-4o`）
- **API Key**：你的 API 密钥

> **API Key 从哪里获取？** 如果你用 OpenAI，在 [platform.openai.com/api-keys](https://platform.openai.com/api-keys) 创建。如果用其他服务商（如 DeepSeek、智谱），请查看对应服务商的文档。

填写后点击 **保存并测试**，系统会验证连接是否正常。Key 会被加密存储，不进日志、不进诊断包。

## 4. 开始使用

设置完成后，你会进入**变化雷达**（Dashboard）。日常使用只需记住四个入口：

| 我要做什么 | 去哪里 |
|-----------|--------|
| 看今天有什么新变化 | **变化雷达** |
| 导入新的视频/网页/文件 | **导入中心** |
| 搜索之前分析过的内容 | **知识搜索** |
| 查看最近的分析报告 | **报告库** |

### 导入第一份资料

1. 打开 **导入中心**
2. 选择资料类型（YouTube 视频、网页、文件/PDF）
3. 输入链接或选择文件
4. 预览确认后开始分析
5. 分析完成后在报告库查看结果

### Obsidian 集成（可选）

SignalVault 可以把分析结果同步到 Obsidian 知识库，但**这不是必须的**。不配置 Obsidian 时，所有核心功能（导入、分析、搜索、变化雷达）仍正常使用。

## 5. 获取帮助

遇到问题时：

1. **导出诊断包**：设置 → 诊断与关于 → 导出诊断包（已自动脱敏，不含密钥和原文）
2. **查看常见问题**：阅读 [FAQ](FAQ.md)
3. **故障排除**：查看 [故障排除指南](TROUBLESHOOTING.md)
4. **提交反馈**：将诊断包和问题描述发送给我们

---

> **隐私说明**：SignalVault 不上传任何数据到云端。所有研究数据存储在本地。AI API 调用只传输分析所需的文本内容。
