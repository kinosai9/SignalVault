# 故障排除

## 启动问题

### 应用无法启动

**症状**：双击 SignalVault.app 没有反应，或启动后立即退出。

**检查步骤**：

1. **确认 macOS 安全设置**：打开系统设置 → 隐私与安全性，查看是否有 SignalVault 被阻止的提示
2. **查看日志**：打开数据目录 `~/Library/Application Support/SignalVault/logs/`，查看 `launcher.log` 中的错误信息
3. **端口冲突**：如果日志显示端口被占用，关闭可能占用 8000 端口的程序（如其他开发工具）
4. **导出诊断包**：如果能短暂打开页面，立即去设置 → 诊断与关于 → 导出诊断包

**如果完全无法启动**：删除数据目录 `~/Library/Application Support/SignalVault/`（这会清空所有数据），然后重新启动。

### 浏览器打开后显示"无法连接"

**症状**：浏览器打开了但页面显示连接错误。

**可能原因和解决**：

1. **服务还在启动中**：等待 5-10 秒后刷新页面
2. **端口不是 8000**：查看日志中"访问地址"那一行，确认实际端口
3. **防火墙阻止**：检查 macOS 防火墙设置，允许 SignalVault 的传入连接

### 显示"检测到 SignalVault 进程仍在运行"

这说明之前的 SignalVault 实例没有正常退出。

**解决方法**：
1. 打开 **活动监视器**（Activity Monitor）
2. 搜索 `signalvault` 或 `python`
3. 选中相关进程，点击强制退出（ⓧ）
4. 重新启动 SignalVault

## AI 配置问题

### AI 连接失败

**症状**：测试连接时显示"连接失败"或"验证失败"。

**检查步骤**：

1. **API Key 是否正确**：确认 Key 没有多余的空格，没有过期
2. **Base URL 是否正确**：地址应该以 `/v1` 结尾（如 `https://api.openai.com/v1`），不要漏掉 `https://`
3. **Model 名称是否正确**：确认模型名称与你的 AI 服务商支持的一致
4. **网络是否正常**：确认能正常访问 AI 服务商的网站
5. **账户余额是否充足**：部分服务商需要预付费

### 错误提示"HTTP 401"

**含义**：API Key 验证失败。

**解决**：
1. 去设置 → AI 服务，重新输入 API Key
2. 确认 Key 没有过期或被删除
3. 确认 Key 有调用模型的权限

### 错误提示"HTTP 429"

**含义**：请求频率过高，被限流。

**解决**：等待几分钟后重试。如果频繁遇到，考虑升级 AI 服务套餐。

## Obsidian 问题

### Vault 路径无效

**症状**：输入 Vault 路径后显示"路径无效"。

**检查**：
1. 路径是**完整的绝对路径**（如 `/Users/你的用户名/Documents/MyVault`），不是相对路径
2. 目录确实存在（在 Finder 中可以打开）
3. 目录有读写权限

### 初始化 Vault 失败

**症状**：点击"初始化 Vault"后报错。

**解决**：
1. 确认 Vault 目录有写入权限
2. 确认 Vault 不是被其他程序独占锁定（关闭 Obsidian 后重试）
3. 如果 Vault 中已有 `.signalvault-manifest.json` 且是由其他工具创建的，会出现 manifest 冲突。这种情况下需要手动删除该文件后重试（注意这会清除之前的初始化记录）

### 只想用 SignalVault，不想用 Obsidian

**完全没问题。** 设置向导中可以直接跳过 Obsidian 配置。所有核心功能（导入、分析、搜索、变化雷达）都不依赖 Obsidian。

## 数据问题

### 数据库异常

**症状**：页面显示数据库相关错误。

**解决**：
1. **导出诊断包**：设置 → 诊断与关于 → 导出诊断包
2. **检查磁盘空间**：确保有足够的可用空间
3. **严重情况**：如果数据库损坏，可以删除 `~/Library/Application Support/SignalVault/signalvault.db` 重新初始化（**注意：这会丢失所有分析数据**）

### 如何恢复之前的数据库

如果你之前备份过数据目录，恢复步骤：
1. 退出 SignalVault
2. 将备份的 `signalvault.db` 复制到 `~/Library/Application Support/SignalVault/`
3. 重新启动 SignalVault

## 获取更多帮助

如果以上步骤无法解决你的问题：

1. **导出诊断包**：设置 → 诊断与关于 → 导出诊断包（已自动脱敏）
2. **收集信息**：描述你遇到的具体情况、操作步骤和看到的错误信息
3. **提交反馈**：将诊断包和问题描述一起发送

诊断包是安全的——所有密钥、原文内容和文件路径都已自动脱敏。
